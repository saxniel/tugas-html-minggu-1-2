A. Profil Saya 🐾

Halo!!! 👋 Nama saya Otniel. Saya adalah mahasiswa aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan yang besar di bidang Public Relation dan Community Management. Selain itu, saya juga memiliki kemampuan di bidang pengembangan aplikasi web, perancangan basis data, serta analisis sistem Informasi. Saya senang memiliki relasi baik dengan orang lain dan menjaga hubungan baik antarperusahaan. Saya senang bertemu orang-orang baru di sekitar saya. Selain itu saya juga memiliki bakat sekaligus hobi di bidang musik. Saya adalah professional session saxophone player. Hobi saya sebagai musisi tersalurkan dengan baik melalui pekerjaan tersebut. Selain saxophone, saya juga bisa memainkan instrumen keyboard dan gitar. Tidak hanya memainkan alat musik, tapi saya juga tertarik mengaransemen lagu ataupun menulis lagu. Menurut saya musik merupakan wadah terbaik untuk mengeksplorasi segala aspek kehidupan kita.

▶ Klik di sini buat baca info tambahan tentang web ini!

Halaman web ini dibuat dengan HTML5 murni tanpa CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan web ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan web ini menjadi salah satu latihan untuk memahami dasar-dasar pengembangan web. Dengan latihan ini, saya berharap dapat memahami HTML dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
